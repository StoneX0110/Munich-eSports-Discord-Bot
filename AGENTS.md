# Codex Instructions

- Python dependencies and command-line modules, including `pytest`, are installed in the project virtual environment at `.venv`.
- Prefer running Python tools through the virtual environment, for example `.venv/bin/python -m pytest`.

# Best practices
Follow software engineering best practices.
Find the best possible solution with minimal code. Try as small as possible and only if that doesn't work, we can expand.

# .md files
.md files explaining command behaviour should be written in simple language, so that end users without technical knowledge can understand and use them.
They shouldn't contain technical details (e.g., how exception handling works or how we match a string).
